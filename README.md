✦ Sobre o projeto

O SIVAD é um protótipo de sistema pensado para apoiar a organização de uma empresa que trabalha com produtos, vendas e estoque. A proposta reúne, em um só lugar, atividades que fazem parte da rotina de administração e atendimento.

Este projeto foi desenvolvido como uma atividade interdisciplinar: uma forma de conectar conhecimentos de diferentes matérias na criação de uma solução para uma necessidade do dia a dia.

✨ O que o protótipo apresenta

•
Área administrativa: uma visão geral e telas relacionadas a produtos, estoque, compras e relatórios.

•
Área de atendimento: telas que representam o registro e o acompanhamento de pedidos.

•
Organização de produtos: cadastro e consulta de produtos e categorias.

•
Experiência visual: páginas planejadas para perfis diferentes de uso, como administração e atendimento.


As telas mostram a proposta e os principais caminhos imaginados para o sistema. Nem todas as ações estão concluídas ou funcionam como em um produto pronto.

🎯 Objetivo

Criar uma representação simples de como ferramentas digitais podem ajudar a reunir informações e tornar mais organizadas as rotinas de vendas e controle de estoque.

🚧 Em que etapa estamos

O SIVAD ainda está em fase de protótipo. A ideia, as telas e parte da estrutura estão representadas, mas o sistema não deve ser entendido como uma solução pronta para uso comercial.

Algumas ações — como entrar no sistema, guardar todos os cadastros e atualizar o estoque automaticamente — ainda não estão concluídas. Por isso, o foco desta versão é apresentar a proposta e a experiência planejada, não oferecer um serviço completo.

🧩 Tecnologias de base

O protótipo foi construído com C#, ASP.NET Core e SQL Server.
